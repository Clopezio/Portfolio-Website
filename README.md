# Umut Hastan — Portfolio

A small static portfolio with no build step or framework.

## Project structure

```text
.
├── index.html              Home page markup
├── about.html              About page markup
├── styles/
│   └── site.css            All presentation and responsive styles
├── scripts/
│   ├── site.js             Navigation, particles, and cursor effects
│   └── analytics.js        Google Analytics setup
├── hero.png                Portrait
├── github.svg              GitHub icon
├── instagram.svg           Instagram icon
└── resume.pdf              Downloadable résumé
```

## Run locally

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.
